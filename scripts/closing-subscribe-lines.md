# Closing subscribe lines: next 5 Shorts (draft)

Channel: **Unreal But True**. Draft for review, not committed to the repo yet.

## How these are built
- **Length:** 8 to 12 words, so it fits the last 2 to 3 seconds without slowing the ending.
- **Voice:** the same plain, confident tone as the top Shorts (Mercury, Blood Falls, Deepest Hole), and the channel promise from the About page: *real things that sound impossible*.
- **Payoff first, ask second.** Each line lands the fact one more time, then asks. No "smash that button", no emoji.
- **"Subscribe", not "Follow".** On Shorts the button says Subscribe, so the word matches what viewers tap.
- **Chained teasers.** Each pinned comment names the next Short, which gives a reason to subscribe today. If the order changes, swap the teaser.

## Topics
Picked to match what already works on the channel: a counterintuitive claim about a planet or place, with a plain title. Swap any topic you already have planned; the line formula still applies.
